## Exact scope

The source asks whether every finite set S of functions of the form
f(x)=sum_i floor(n_i x), with each n_i a positive integer, has some positive
real x at which one member is strictly smaller than every other member.
The functions are actual functions, so duplicate representations do not
give different members of S. No distinctness of the integers n_i is imposed.
The MSE comments explicitly use repeated summands, and the author says the
number k of summands need not be common to the different functions.

The example below uses four distinct functions, all with exactly four
summands and all positive integer coefficients n_i. It therefore avoids
any empty-set, singleton, repetition-of-functions, or unequal-length issue.

## Counterexample

Let S={f1,f2,f3,f4}, where

| Function | Positive integer list (n_i) | Formula |
|---|---|---|
| f1 | (2,2,2,3) | 3 floor(2x)+floor(3x) |
| f2 | (1,2,3,3) | floor(x)+floor(2x)+2 floor(3x) |
| f3 | (1,2,2,4) | floor(x)+2 floor(2x)+floor(4x) |
| f4 | (1,1,3,4) | 2 floor(x)+floor(3x)+floor(4x) |

Their values at x=1/4 and x=1/3 respectively are
f1:(0,1), f2:(0,2), f3:(1,1), f4:(1,2).
Consequently these are four distinct functions.

Put

F(x)=f2(x)-f1(x)=floor(3x)-2 floor(2x)+floor(x),

G(x)=f3(x)-f1(x)=floor(4x)-floor(3x)-floor(2x)+floor(x).

An exact cancellation gives f4=f1+F+G. Both F and G have period 1:
for an integer m, floor(r(x+m))=rm+floor(rx), and the total linear
coefficients in each of F,G are zero. Thus reduce any real x to
t=x-floor(x), with 0<=t<1. This reduction includes negative x as well.

The complete interval table is

| Interval for t | (floor(2t),floor(3t),floor(4t)) | F(t) | G(t) |
|---|---|---|---|
| [0,1/4) | (0,0,0) | 0 | 0 |
| [1/4,1/3) | (0,0,1) | 0 | 1 |
| [1/3,1/2) | (0,1,1) | 1 | 0 |
| [1/2,2/3) | (1,1,2) | -1 | 0 |
| [2/3,3/4) | (1,2,2) | 0 | -1 |
| [3/4,1) | (1,2,3) | 0 | 0 |

All left endpoints are included and all right endpoints are excluded,
exactly as required by the floor function. Hence F(x)=0 or G(x)=0
for every real x.

If F(x)=0, then f1(x)=f2(x) and f3(x)=f4(x). If G(x)=0, then
f1(x)=f3(x) and f2(x)=f4(x). Thus every function value at any x has
an equal value at another distinct member of S. No member can be
strictly smaller than all the other members. This disproves the source
assertion for every positive x, and indeed for every real x.

The final Lean argument uses a shorter global proof suggested by root.
Write m=floor(x), a=floor(2x), b=floor(3x), c=floor(4x). The standard
floor-addition lower and upper bounds give

2m <= a <= 2m+1,
a+m <= b <= a+m+1,
b+m <= c <= b+m+1,
2a <= c <= 2a+1.

These eight integer inequalities imply b-2a+m=0 or c-b-a+m=0.
Indeed A=a-2m is 0 or 1. If A=0, then B=b-3m is 0 or 1; B=0
gives F=0, and B=1 forces C=c-4m=1, giving G=0. If A=1,
then B is 1 or 2; B=2 gives F=0, and B=1 forces C=2, giving G=0.
The Lean certificate obtains all eight bounds from Int.le_floor_add and
Int.le_floor_add_floor and closes this integer implication with omega.
It proves all six pairwise function inequalities by exact evaluations
at 1/4 or 1/3 and then contradicts the full finite-family assertion.
