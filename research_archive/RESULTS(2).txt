INTERPRETATION
--------------
The algorithm was not told any target coordinates, edge sets, symmetry groups,
or Platonic-solid names.

It was given only:

    random possibilities,
    a conserved spherical boundary,
    a rotationally invariant ordering functional,
    the same bounded URT recursion,
    monotone admissibility.

The output depended on the available state count and converged to a canonical
closed structure.

This is a computational demonstration of:

    unorganised possibility
    -> recursive admissibility
    -> contraction
    -> canonical structure.

It is a proof-of-mechanism simulation, not evidence that every physical or
mathematical system uses this exact entropy functional.
