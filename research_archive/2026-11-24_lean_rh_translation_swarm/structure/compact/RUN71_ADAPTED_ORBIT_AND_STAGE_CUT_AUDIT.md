## 1. Equal adapted valuations imply the required Bessel orbit

Let F=X_f x, F'=X_f x', B,B' their adapted bases, with triangular order 4i+1 on string i and 2s on X. Write K=B^-1 F, K'=B'^-1 F' in GL(O_hat); their inverses are integral. For every first-half string index i<=rev(i) suppose the diagonal ideles beta_i,beta'_i have equal valuations at ALL finite places. Rescale column i of B' by beta_i/beta'_i, a unit of O_hat, leaving other columns unchanged. K' remains integral invertible, and the first-half diagonals now agree as ideles, not just in norm. Let I be this first-half index set (including middle in odd length). The columns C=(K^-1)_I and C'=(K'^-1)_I are primitive: the corresponding rows of K and K' are integral left inverses. Their Gram matrices agree: (K^-1)^*K^-1=B^* J B, using F^* J F=1. For i,j in I, the only nonzero entry of this restricted Gram can be the central entry when s is odd, equal to -N conjugate(beta_i) beta_i. Indeed each column i in I has support only on string indices <=i (since 4i+1<2s), and reversed indices pair only if their sum is s-1; the only such pair within these supports is the odd central pair. Thus the actual hypotheses of integral Witt apply, giving g in Kf with g C=C'. Define U=F' g F^-1. Then U B_I=B'_I. For every j in I, B e_j=beta_j e_j+sum_{a<j} B_aj e_a and similarly for B'; induction on j gives U e_j=e_j+sum_{a<j} u_aj e_a, since beta_j is invertible and the two beta_j coincide. This is precisely the Bessel condition at each nonnegative string grade: grade(a)=s-1-2a is strictly larger for a<j. No constraint is imposed on X columns by this argument; the native unitary membership supplies the correct extension. Therefore x' g x^-1 belongs to besselFin. This proves the actual orbit implication without a general orbit classification or a new Witt premise. The s=0 case has no string conditions and is immediate.

The valuation comparison in the same file needs only a single diagonal entry: if F^-1 F' integral at w, then B^-1 B'=K(F^-1 F')K'^-1 integral at w, with diagonal string entry beta'_i/beta_i, by block triangularity. Thus log beta'_i<=log beta_i (log=-ord). If F and F' have equal local components the reverse inequality holds too. More generally the equality of local lattices suffices, since both transition matrices are integral. This will be used below with a column permutation, not an unsupported equality of matrices.
