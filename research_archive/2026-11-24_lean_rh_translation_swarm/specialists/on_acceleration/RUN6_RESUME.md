## Contract and proof of preservation
Input manifest typed-csr-input-v1 carries source repository, commit, graph kind, provenance, node/edge counts, SHA256 of two NDJSON files. Caller supplies independently trusted manifest SHA256. Names are ordered by strictly increasing original numeric export ID; row index is dense ordinal. The tagged name is a nonempty array of strings or nonnegative integers, so a numeric name component is not a string of the same digits. Exact tag uniqueness is checked by a disk SQLite B-tree. Edge records are dense u,v plus nonempty role and kind; arbitrary extra evidence fields and original bytes retained in the copied sidecar. Counts, ranges, duplicate JSON keys, hash mismatch, oversized records and duplicate tags fail closed. These checks establish structural integrity only; a digest is not an independent verification of the projection, and the caller must authenticate the source/export and typed role evidence. Graph kind is explicit: synthetic, export-fixture-package-projection, static-source or elaborated-projection; the latter requires original RH pin. No premise deleted. The converter accepts already densely mapped edges, it does not yet map arbitrary raw IDs to ordinals.

For each orientation, first count degrees d_i on disk, then compute prefix offsets o_i=sum_{j<i}d_j. Row i's storage interval is [o_i,o_{i+1}). Set disk cursor to o_i. Replay exact verified input edge records, write neighbor into next slot, advance cursor. Bounds and final cursor checks imply each slot is written once and each input edge contributes once to each orientation. Reverse uses swapped endpoints of the identical record, hence exactly the transpose including duplicates, cycles and per-row input order. Output forward and reverse off/adj match Run5 Reader layout. SHA256 output receipt covers both sidecars, original manifest and both arrays; staging directory renamed under cooperative exclusive lock only after all checks. Not adversarial filesystem protection or power-loss durability; process kill can leave a stale lock/staging directory. No in-memory adjacency array. Complexity O(B+V+E) graph construction plus disk tagged-name B-tree uniqueness O(V log V) key operations (variable key byte costs additionally counted). Two passes over edges; positional random I/O locality affects wall time. Fixed-size Python reads bounded by 1 MiB records and file digest buffers; SQLite page cache target 1 MiB, not a strict bound on entire process. Output arrays total 16(V+1)+8E bytes, scratch cursors 16V bytes plus disk tag database during name phase. Sidecar bytes and interpreter/OS overhead extra.
