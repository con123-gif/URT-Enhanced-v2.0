- For each module m in dependency-first topological order, compute H_m = SHA256(version, environment digest, module identity, exact blob ID, ordered list of (import name, H_import)). Unresolved names are explicit boundaries, not silently erased. Lexically flagged modules, missing imports and their dependants are not marked lexically clean/closed. This eligibility is only a lexical property, never evidence of semantic reuse or proof validity.
- A changed context key conservatively invalidates that module's downstream translation evidence. An environment digest change invalidates all keys. A deleted local import changes its parent's context to a boundary. Cycles fail closed. The theorem for *the represented DAG*: if the input fingerprint tuple for a node changes, its digest changes barring collisions; by induction a changed reachable prerequisite propagates to each ancestor. Unrepresented dependencies are outside this theorem.

No namespace resolution or exact declaration dependency graph yet. Unsupported lexical constructs are flagged where detected; flags are not exhaustive. Retain raw Git object as authority.
- O(B_miss + V + E + C) core parsing, topological traversal and context hashing for B_miss bytes newly opened, V modules, E represented import edges, C candidate declarations (count token/identifier length in input size). Per-key SQLite lookups/inserts have B-tree costs; tree enumeration, manifest output, cache IO, Git compression/delta costs and full context regeneration remain. Not an O(k) whole-index update; per-edit source reparse is limited to changed blobs. Peak memory O(V+E+C+largest blob), not constant. No universal O(N) proof search.
