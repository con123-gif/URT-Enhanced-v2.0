# Pre-registration: where the Q = 2/3 rule applies, and what it predicts for neutrinos (18 Oct 2026, before computing)

Rule (derived earlier this session): for one configuration of three identical generations, maximum entropy over the
only two basis-free pieces of the sqrt-mass operator X gives Tr X^2 = (2/3)(Tr X)^2, i.e. Q = 2/3. X is the Dirac
operator (Cathedral K = D^2), so its eigenvalues are signed: Q is evaluated on signed square roots.

Domain claim: the rule is a statement about the physical spectrum of free particles (pole masses). It is not a
statement about running masses, and it has no object for confined quarks (no pole spectrum for u, d, s; renormalon
ambiguity for c, b). Quark Q values built from MS-bar masses are therefore not a test of it.

T1 (domain check on leptons): Q from pole masses vs Q from one-loop QED running masses at M_Z.
    Pass if pole Q is within 3 sigma of 2/3 AND running Q misses 2/3 by more than 10x the pole error bar.
T2 (neutrino solutions): with current oscillation data, solve Q = 2/3 for both orderings and every sign pattern.
    Report every solution: masses, lightest mass, sum, m_beta.
T3 (cosmology): pass if at least one T2 solution has sum below the current 95% cosmological bound (LambdaCDM).
    The surviving ordering is the prediction.
T4 (phase relation; Brannen 2006 hypothesis, not constructed here): delta_nu = delta_e + pi/12,
    i.e. 3 delta_nu = 3 delta_e + pi/4. With Q = 2/3 this fixes R = dm2_21 / dm2_31.
    Pass if within 3 sigma (session standard) of measured R. Report the pull for each input set.

Data: CODATA 2022 m_e, m_mu/m_e; PDG 2026 m_tau; latest NuFIT global fit; JUNO first Delta m^2_21 if published;
DESI DR2 + CMB bound on the sum of neutrino masses.
