# legacy/

This directory contains code and documents from earlier versions of the framework
that were heavily oriented toward physics predictions and constant derivations.

These are preserved for historical reference and to avoid breaking any external
references during the transition of the `grok-review` branch to a pure
mathematical focus (G₁₃ geometry + URT + Lytollis’s Law).

See `BRANCH_DIRECTION.md` and the current `README.md` for the active philosophy.

Files here should generally not be imported in new work on this branch.
